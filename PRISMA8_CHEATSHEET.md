# Prisma 8 (Prisma Next) Cheat Sheet

Prisma 8 is a "contract-first" data layer, which fundamentally changes how the CLI and runtime operate compared to Prisma 7. 

This guide maps the commands you used in Prisma 7 to their new Prisma 8 equivalents.

## 1. Generating / Compiling

In Prisma 8, you don't generate a heavy Node.js client. Instead, you "emit" your contract into a lightweight JSON file and TypeScript definitions that the dynamic runtime uses.

| Action | Prisma 7 | Prisma 8 |
| :--- | :--- | :--- |
| **Apply schema changes to code** | `prisma generate` | `npx prisma contract emit` |

*Note: You can also use the npm script we set up: `npm run contract:emit`*

## 2. Local Development (No Migration Files)

When you are iterating locally and don't care about keeping a history of SQL migration files, you can push your changes directly to the database.

| Action | Prisma 7 | Prisma 8 |
| :--- | :--- | :--- |
| **Push schema to DB directly** | `prisma db push` | `npx prisma db update` |

*Note: You can also use the npm script we set up: `npm run db:push`*

## 3. Migrations (Version Control)

Prisma 8 strictly separates **planning** a migration (creating the files on disk) from **applying** it to the database.

| Action | Prisma 7 | Prisma 8 | Notes |
| :--- | :--- | :--- | :--- |
| **Create a new migration** | `prisma migrate dev` | `npx prisma migration plan --name <name>` | Creates migration files on disk, but does **not** touch the live database. |
| **Apply pending migrations** | `prisma migrate deploy` | `npx prisma db migrate` | Runs the migrations generated by `migration plan` against your database. |
| **Preview migrations** | `prisma migrate status` | `npx prisma db migrate --show` | Shows the ordered list of migrations that are pending execution. |

## 4. Introspection (Existing Databases)

If you have an existing database and want to pull its schema into Prisma, or if you need to tell Prisma that the database is already up to date without running migrations.

| Action | Prisma 7 | Prisma 8 | Notes |
| :--- | :--- | :--- | :--- |
| **Pull schema from DB** | `prisma db pull` | `npx prisma contract infer` | Reads an existing database and generates a `contract.prisma` file for you. |
| **Baseline an existing DB** | `prisma migrate resolve` | `npx prisma db sign` | Tells Prisma "the database already matches the contract, mark it as up-to-date". |
